# Changelog

## 0.1.0 — 2026-10-19

First executable release candidate.

- Local repository inventory with generated-directory exclusions and practical ignore-file support.
- Python AST module metrics and import extraction without importing or executing target code.
- Static internal dependency graph and strongly connected import-cycle detection.
- Entry-point signals, external import inventory, and structural findings.
- Versioned JSON snapshots plus Markdown, Mermaid, and standalone SVG exports.
- CLI output safeguards, scan limits, tests, examples, and cross-platform CI.

This alpha analyzes Python syntax only; multi-language parsers and interactive graph navigation are not included.
